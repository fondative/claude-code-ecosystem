Documentation technique — Legacy Classified Ads Script ​

Analyse par rétro-ingénierie du projet php-legacy/ (application PHP de petites annonces, v1.0.2, GPL v3). Objectif : servir de référence pour la compréhension, la maintenance et la migration vers la cible Symfony 7.4 / PHP 8.2 / PostgreSQL + React 19. Date d'analyse : 07/10/2026 — analyse statique du code source (lecture seule).

Fiche d'identité ​

ÉlémentValeur
TypeMonolithe PHP « vanilla » rendu côté serveur (page controllers + templates)
StackPHP 5.6 / Apache 2 / MySQL 5.5 / XHTML + CSS + JS vanilla, Docker Compose
Volume177 fichiers, 137 fichiers PHP, ~10 700 lignes PHP (hors PEAR Pager)
Points d'entrée25 scripts publics, 37 scripts d'administration
Base de données12 tables InnoDB, aucune clé étrangère
TestsAucun
Risques majeursInjections SQL non authentifiées, upload de fichier exécutable, mots de passe en clair, XSS généralisé, pile hors support

Conventions ​

  • Les références de code sont exprimées en fichier:ligne, relativement à la racine php-legacy/.
  • Criticité : CRITIQUE > ÉLEVÉE > MOYENNE > BASSE.
