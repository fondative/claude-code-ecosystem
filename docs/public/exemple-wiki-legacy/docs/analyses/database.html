4. Couche d'accès aux données ​

4.1 Classe db (admin/include/db.php) ​

  • Wrapper mysqli instancié une fois en global ($db) dans common.php:37.
  • Un seul résultat courant partagé ($db->rs) : les appels imbriqués écrasent le résultat précédent.
  • Méthodes prepare / bind_param / execute disponibles mais utilisées uniquement par TreeTable::get_tree().
  • En cas d'échec de connexion : exit( mysql_error() ) (common.php:38) — appel à l'extension mysql obsolète, sans rapport avec la connexion mysqli.
