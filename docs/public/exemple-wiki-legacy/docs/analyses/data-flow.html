2.2 Autorisation sur les annonces (liens à jeton) ​

La modification, l'extension et la suppression d'une annonce reposent uniquement sur la connaissance du couple id + code (md5 de uniqid(rand(), true)) transmis par email. Il n'y a aucun lien avec la session utilisateur : un utilisateur connecté ne peut pas gérer ses annonces depuis son compte (le lien « My Ads » est une recherche par email, page-right.php:55).

3. Points d'entrée HTTP (pas d'API REST) ​

L'application n'expose aucune API JSON. Les « endpoints » sont des scripts PHP rendant du HTML.
