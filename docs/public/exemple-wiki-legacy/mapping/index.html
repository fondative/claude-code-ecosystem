Prête à migrer

15 features

Lecture : une flèche A → B signifie « A dépend de B » (B doit être migrée avant A). Taille d'un nœud = nombre de features qui en dépendent. Anneau cyan = prête à migrer (toutes ses dépendances terminées). Pourcentage = tâches réalisées. Vagues : ordre de migration recommandé (vague 1 = sans dépendance). Arbre : clic sur une feature = déplier ses fonctionnalités et afficher son détail (second clic : replier). Clic sur une feature : sa chaîne de dépendances (en bleu) et les features qu'elle débloque (en orange). Molette : zoom · glisser : déplacer. Données calculées au build depuis output/, identiques aux tableaux de bord.
